Lunaris Design System Specimen

Design system for Lunaris Collectibles & Memorabilia, an active duty service member owned shop in Tacoma, WA that makes laser-engraved trading card binders and custom military gifts.

Audience: Trading card collectors and families, plus service members and veterans shopping for personalized gifts. On Etsy, Facebook, and local pop ups at card shows in Washington state.

GIT 337 · Jess Juarez · Real business, used with the owner's permission.

S1: Foundation and Reset

I kept my reset simple and only changed a few browser defaults that were causing issues:

  • box-sizing: border-box on all elements
  • margin: 0 on the body
  • max-width: 100% on images
  • font: inherit on inputs, selects, and buttons

Why border-box: this keeps the padding and borders within the width I set, so the cards fit better on smaller screens.

Why font: inherit: some browsers use a different font for buttons and inputs. This makes them match the rest of my page.

What I kept: I left the focus outlines, bullet points, and normal heading and paragraph spacing because they make the page easier to read and use.

Font documentation

  • Display (headings): DM Serif Display, Georgia, serif. I picked this because it looks similar to the LUNARIS lettering in the logo.
  • Body: Montserrat, Arial, sans-serif. I picked this to match the COLLECTIBLES lettering in the logo.
  • Source and license: I got these from Google Fonts. They use the SIL Open Font License, so they are free to use. I loaded DM Serif Display 400 and Montserrat 400 and 700.
  • Responsive sizing: I used a media query to make the headings bigger when the screen is 48em (768px) or wider.
  • Line length: I limited paragraphs to 65ch so the lines do not stretch too far across the page.
  • Fallback plan: I used display=swap so the text still shows while the fonts load. If Google Fonts does not load, the headings use Georgia and the body text uses Arial.

Theme and Accessibility Notes

How the theme works: I used one CSS rule called .theme-moonlit to change the colors. When I add this class to a box, it uses the Moonlit colors. I did not need to write separate button, card, or form styles for each theme.

Contrast: the original logo red was hard to see against the dark background, so I used a lighter coral and dark button text for Moonlit. The text meets WCAG AA contrast requirements (4.5:1). I also used a black focus outline for Daylight and a gold one for Moonlit to make them easier to see.
